def message_problems(text, *, ai_turn, copies):
    copy: normalize(text) in copies          # 초안과 완전히 같음
    greeting: is_daily_greeting(text)        # 일상 인사·재만남 여지
    closing: ai_turn >= 3 and not is_closing_message(text)
    length: len(normalize(text)) > 200
# 문제가 있으면 사유 notice 를 모두 붙여 한 번만 다시 쓰고, 무게(greeting 3, closing 2, copy 1, length 1)가 같거나 낮으면 채택
if "greeting" in problems: raise LLMError(...)                 # → FAILED
if "closing" in problems: 뒤에 CLOSING_SUFFIX("마지막으로, 더 이상 답장하지 않고 이 채팅은 여기서 종료할게요.") 덧붙임
# 3턴: closing 이 ai_response 에 없으면 뒤에 이어 붙임 (agents.py:462-464)

### 1-3. 발견 사항

1. **질문 금지를 코드가 확인하지 않는다.** 기능 17은 `?`가 있으면 폴백하지만, `message_problems`에는 질문 검사가 없다(`agents.py:392-405`). 가드레일도 질문 2개 이상만 잡는다(`engine.py:169`). 질문 1개짜리 종료 메시지는 그대로 나간다. R-07은 평가 코드 체크로 넣는다.
2. **초안 복사 검사는 완전 일치만 본다.** 한두 글자만 바꾼 복사는 통과한다(`agents.py:396`). 기준서의 "초안 단순 복사 금지"를 재려면 유사도 기준(예: 문자 유사도 0.9 이상)을 정해야 한다.
3. **3턴 종료 문장이 코드로 덧붙으면 200자를 넘을 수 있다.** closing을 이어 붙이고(`agents.py:462-464`), 그래도 종료 표현이 없으면 고정 문장을 또 붙인다(`:449-451`). 길이 검사는 그 전에 끝나므로 최종 문장이 200자를 넘는지 따로 본다.
4. **제품 실패가 빈 응답이다.** 폴백 문장을 내보내지 않으므로(`service.py:9-11`) 실패율이 곧 사용자 체감 실패율이다. FAILED 비율을 Gate 2 기술 오류율에 넣는다.
5. **재작성은 한 번이고, 더 나빠지면 원래 것을 쓴다.** 무게 비교로 고르므로(`agents.py:440-443`) 재작성 후에도 copy·length 문제가 남은 메시지가 SUCCESS로 나갈 수 있다. 제품 점수에서 copy·length 잔존율을 따로 센다.
