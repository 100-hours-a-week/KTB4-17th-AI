6.추출 척도

차원 판정 분류 (점수형 15개 차원을 사례마다 하나씩)

모델이 키를 생략모델이 점수를 냄
답하지 않은 차원정답 생략 (TN)환각 (FP)
답한 차원누락 (FN)범위 안 → 정답 (TP) 범위 밖 → 오차 (TP✗)
차원 판정 정확도 = (정답 생략 + 범위 안 정답) / 전체 차원 수
단계지표정의기준
1단미답변 차원 점수 / 유형명 / 복창 / JSON 실패E3-CRIT-01~03 + 스키마0건
2단차원 판정 정확도 ← 대표 지표위 식우수 ≥ 0.95 · 합격 ≥ 0.90
2단환각률답하지 않은 차원에 점수를 낸 비율0%에 가깝게
2단누락률답한 차원에 점수가 없는 비율≤ 3%
2단범위 적중률허용 범위 안에 든 점수 비율≥ 0.88 (Gemini 92%)
2단구간 일치율 (teacher 비교)낮음(<35) / 중간 / 높음(>65) 구간 일치≥ 0.90
2단MAE (teacher 비교)점수 차이 평균≤ teacher 노이즈 바닥 × 1.5
2단서술 자동 점수짐작 없음, 모순 없음, 가드레일 통과, 길이 계약, 문장별 인용의 평균 통과율≥ 0.9
2단summaries 생존율필터를 통과한 카드 비율보고
3단서술 1/3/5 또는 쌍대 비교teacher와 student 블라인드 비교평균 ≥ 3 / 지지 않는 비율 ≥ 45%

텍스트형 4개(관심사, 루틴, 데이트 선호·기피)는 같은 분류를 쓰되, "범위 안" 대신 항목이 사용자 발화에 근거하는지로 판정합니다.
