# 얼굴 인증을 온보딩의 필수 단계로 한다

라이브니스 기반 얼굴 인증을 가입 이후의 선택 절차가 아니라 온보딩 중 모든 사용자가 거치는 필수 단계로 바꾼다. 대표 사진 심사(정면·품질, 합성 위험)를 통과한 직후 라이브 촬영으로 대표 사진 속 인물과 현재 사용자가 같은지 확인하고, `VERIFIED` 를 받아야 가입이 완료된다. 사칭 계정이 매칭에 노출되기 전에 막는 것을 가입 장벽보다 우선하기 위한 결정이며, ADR 0001 중 "온보딩에서는 카메라 촬영을 요구하지 않고 얼굴 인증은 선택"이라는 부분을 대체한다. 사진 심사와 얼굴 인증을 별도 단계로 나누는 결정(ADR 0001)과, 인증 마크를 현재 대표 사진에 결합하고 사진이 바뀌면 해제하는 결정(ADR 0003)은 유지한다. 필수가 되면서 오거부(FRR)가 곧 가입 실패가 되므로 FAR 와 함께 FRR 상한도 배포 기준으로 두고, 재촬영 안내와 재시도 한도는 메인 백엔드가 관리한다.
