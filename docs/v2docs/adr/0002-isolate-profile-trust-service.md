# 프로필 신뢰 기능을 독립 AI 서비스로 분리한다

프로필 사진 심사와 얼굴 인증은 프론트엔드 및 기존 백엔드와 분리된 독립 API 서비스가 담당한다. AI 서비스는 모델별 세부 점수를 안정적인 판정과 사유 코드로 변환해 반환하고, 사용자·사진·인증 상태·인증 마크는 기존 백엔드가 소유한다. 이 경계는 모델과 외부 공급자를 교체할 수 있게 하면서 생체정보 처리 책임이 기존 제품 도메인으로 확산되는 것을 줄이기 위한 것이다.

## 갱신 (2026-10-06)

배포 단위는 분리하지 않고 기존 AI 서버(`app/features/`)에 기능으로 병합한다. dev·운영 CD가 하나의 이미지만 빌드하고 있어 서비스를 하나 더 두는 비용이 크기 때문이다. 위의 책임 경계는 그대로 유지한다. 프로필 신뢰 기능은 LLM·DB를 쓰지 않고 판정과 사유 코드만 반환하며, 사용자·사진·인증 상태·인증 마크는 기존 백엔드가 소유한다.
