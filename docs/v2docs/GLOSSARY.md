# Profile Trust

성인 데이팅 서비스에서 프로필 사진의 기본 적합성을 심사하고, 선택적으로 현재 사용자와 사진 속 인물의 일치 여부를 인증하는 영역이다. 법적 신원, 실명 또는 연령을 증명하지 않는다.

## Language

**프로필 사진 심사 (Profile Photo Screening)**:
업로드된 사진이 사진 유형에 맞는 등록 기준을 충족하는지 평가하는 절차. 현재 사용자와 사진 속 인물의 동일인 여부는 보장하지 않는다.
_Avoid_: 본인 인증, 얼굴 인증, 신원 확인

**대표 사진 심사 (Primary Photo Screening)**:
대표 사진에 사용자 한 명의 정면 얼굴이 선명하게 나타나고 합성 신원 사진의 강한 증거가 없는지 평가하는 절차.
_Avoid_: 얼굴 인증, 추가 사진 심사

**추가 사진 심사 (Additional Photo Screening)**:
추가 사진의 기본 안전성과 합성 위험을 평가하는 절차. 단체·전신·취미 사진처럼 여러 얼굴이 있거나 얼굴이 없는 사진도 허용한다.
_Avoid_: 대표 사진 심사, 얼굴 인증

**얼굴 인증 (Face Verification)**:
라이브니스 검사를 통과한 현재 사용자의 얼굴과 프로필 사진 속 얼굴이 같은 사람인지 일대일로 확인하는 선택적 절차.
_Avoid_: 실명 인증, 신원 인증, KYC

**인증 시도 (Verification Attempt)**:
로그인한 사용자가 현재 대표 사진을 대상으로 시작한 한 번의 선택형 얼굴 인증 흐름. 사용자와 대표 사진의 소유권을 확인한 메인 백엔드가 생성하고 상태를 관리한다.
_Avoid_: AI 인증 세션, 라이브 촬영 챌린지

**라이브 촬영 챌린지 (Live Capture Challenge)**:
AI 서비스가 인증 시도 중 요구할 촬영 동작과 만료 시각을 서명한 단기 지시. 사용자 로그인 상태나 권한을 나타내지 않는다.
_Avoid_: 인증 세션, 액세스 토큰, 로그인 토큰

**라이브니스 검사 (Liveness Check)**:
카메라 입력이 사진, 녹화 영상 또는 마스크가 아니라 현재 카메라 앞에 있는 실제 사람에게서 나온 것인지 평가하는 절차.
_Avoid_: 셀카 확인, 실물 확인

**인증 프로필 (Verified Profile)**:
얼굴 인증에 성공하여 현재 사용자와 프로필 사진 속 인물의 일치가 확인된 프로필. 법적 신원이나 실명이 확인되었다는 의미는 아니다.
_Avoid_: 실명 인증 사용자, 신원 보증 사용자

**인증 마크 (Verification Badge)**:
현재 대표 사진을 대상으로 얼굴 인증을 통과했음을 나타내는 표시. 대표 사진이 변경되면 즉시 효력을 잃는다.
_Avoid_: 실명 인증 마크, 신원 인증 마크

**인증 기록 (Verification Record)**:
얼굴 인증의 결과, 수행 시각, 대상 대표 사진, 모델 버전을 기록한 정보. 라이브 셀피나 얼굴 임베딩은 포함하지 않는다.
_Avoid_: 생체정보 원본, 얼굴 템플릿

**합성 신원 사진 (Synthetic Identity Image)**:
얼굴 전체가 생성되었거나 얼굴 교체·딥페이크로 사진 속 인물의 신원이 만들어지거나 변경된 사진.
_Avoid_: 모든 AI 편집 사진

**합성 위험 (Synthetic Risk)**:
픽셀 기반 탐지 모델이 합성 신원 사진일 가능성을 발견했지만 강한 출처 증거로 확정하지 못한 상태. 해당 사진 대신 다른 사진을 요청할 수 있으나, 계정 제재나 AI 생성 확정의 근거로 사용하지 않는다.
_Avoid_: AI 생성 확정, 부정 사용자

**일반 보정 (Ordinary Retouching)**:
사진 속 인물의 신원을 바꾸지 않는 피부 보정, 밝기 조정, 색상 조정 또는 배경 제거 등의 편집.
_Avoid_: 합성 신원 사진

**대상 사용자 (Eligible User)**:
대한민국에서 서비스를 이용하는 만 19세 이상 만 39세 이하의 사용자.
_Avoid_: 전 연령 사용자, 미성년 사용자

**연령 자기신고 (Self-Declared Age)**:
사용자가 입력한 생년월일을 기준으로 계산한 연령. 외부 본인확인이나 신분증으로 검증된 연령은 아니다.
_Avoid_: 연령 인증, 성인 인증

**대표 사진 (Primary Profile Photo)**:
프로필을 대표하며 사용자 한 명의 얼굴만 포함하는 사진. 얼굴 인증은 이 사진 속 얼굴을 기준으로 수행한다.
_Avoid_: 인증 사진, 신원 사진

**추가 사진 (Additional Profile Photo)**:
대표 사진 외에 프로필에 등록되는 사진. 프로필 사진 심사 대상이지만 얼굴 인증의 비교 기준은 아니다.
_Avoid_: 대표 사진, 인증 사진

**선택형 인증 제안 (Optional Verification Prompt)**:
온보딩 마지막에 사용자가 건너뛸 수 있는 얼굴 인증 안내. 건너뛴 후에도 프로필에서 다시 시작할 수 있다.
_Avoid_: 필수 인증, 가입 인증
