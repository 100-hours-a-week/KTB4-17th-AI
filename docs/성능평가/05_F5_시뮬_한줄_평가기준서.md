## 1. 프롬프트 요구사항 및 코드 동작 분석

### 1.1 입출력 형식 및 기본 제약
* **형식**: JSON 단일 키 객체 (`{"text": "..."}`)
* **길이 및 스타일 제약**:
  * 300자 이하, 1~3문장.
  * 존댓말, 이모지 일체 금지(가드레일 `WARN`), 가벼운 "ㅎㅎ"만 허용.
  * AI·챗봇·페르소나 연기 금지.
  * **자신의 닉네임에 '님' 붙이기 금지 (`self_addressed`)**:
    * 닉네임이 2자 이상이고 `닉네임님` 형태일 때 감지. 상대방을 부를 때만 '님' 사용 (상대 호칭은 매 턴 강제가 아님).
* **이름표 접두어 처리**:
  * 모델이 종종 `가민: 안녕` 형태로 출력하므로, 코드는 `strip_name_prefix`를 통해 접두어를 제거한 뒤 가드레일 및 저장에 넘김 (모델 원문과 제품 문장의 차이 발생).

### 1.2 대화 아크(Phase) 단계별 실제 규칙 (`arc_phase_for`)
코드가 반환하는 아크 단계는 `open`, `middle`, `late`, `close_a`, `close_b` 5개이며, 첫 줄은 별도 분기로 처리됨:

| Turn Index | 화자 | `arc_phase_for` | `closing_hint_for` | 주입되는 실제 프롬프트 지시 |
| :---: | :---: | :---: | :---: | :--- |
| **0** | **A** | open | none | **`OPENER`** (메신저 첫 인사, 상대 닉네임, 처음 인사 언급, 가벼운 하루 질문, 구체적 장소/약속 금지) |
| **1** | **B** | open | none | **`HINT_OPEN`** (가벼운 인사 후 주말/관심사 전환, 자기 프로필만 언급, 약속/작별 금지) |
| **2** | **A** | middle | none | **`HINT_MIDDLE`** (성향/템포 차이 한 번 솔직히 드러냄, 같은 제안/거절 되풀이 금지) |
| **3** | **B** | middle | none | **`HINT_MIDDLE`** |
| **4** | **A** | close_a | no_new_question | **`HINT_NO_NEW_QUESTION`** (마지막 왕복, 새 질문/새 화제 금지) |
| **5** | **B** | close_b | close | **`HINT_CLOSE`** (마지막 말에 답변 + 약속/짧은 작별 인사로 대화 종료) |

*(참고: `late`(`HINT_LATE`) 단계는 4왕복 이상의 장기 대화에서만 발생함. 따라서 3왕복 6줄 벤치마크에는 `late`가 포함되지 않으며, `late` 검증은 4왕복 이상 모니터링 셋에서 수행함)*

### 1.3 하드 룰 및 탐지기 오라클 동작 원리
1. **발화 반복 탐지 (`repeats_previous`)**:
   * 공백 및 `ㅎㅎ`, `ㅋ`, `!`, `.`, `~`, `?`, `？`를 제거한 후 **12자 이상**일 때만 `SequenceMatcher` 유사도 **0.82 이상**을 반복으로 판정.
   * *한계*: 12자 미만의 짧은 문장은 완전히 동일해도 코드가 탐지하지 못함.
   * *런타임*: 1회 `REPEAT` 재생성 시도 후, 2회차에서도 반복되면 제품 문장으로 그대로 저장됨 (`reason=None`).
2. **이른 작별 탐지 (`contains_farewell`)**:
   * 대상: `closing_hint == "none"`인 모든 턴 (마지막 2줄 제외 전 구간).
   * 탐지 키워드: `들어가`, `나중에 봐`, `나중에 봬`, `또 봐`, `연락할게/게요`, `연락드릴`, `잘 자`, `좋은 밤`, `좋은 저녁`, `편안한 밤`, `조심히`.
   * *주의*: "서점에 들어가 보고 싶어요"처럼 '들어가'의 일상 용법이 오탐될 수 있음.
   * *런타임*: 1회 재생성 후 여전히 작별이면 저장됨.
3. **마지막 턴 종료 실패 제어**:
   * 화자 B의 `close_b`에서 물음표(`?`, `？`)가 포함되면 1회 재생성 후에도 남을 시 `reason="closing_failed"`, `text=None`으로 실행 중단.
   * 화자 A의 `close_a`는 프롬프트 상 새 화제 금지이지만, 물음표가 있어도 코드가 실행을 중단시키지는 않음 (정성 평가로 감점).

## 5. 배포 게이트 합격 기준 (Gate Policy)

본 게이트는 **골드셋 확정 및 도메인 전문가 2인 앵커 승인 후** 공식 적용됨.

### 5.1 사전 차단 (Gate 1 - 치명 결함 0건)
- 대상: **모델 원문 첫 완성 초안**
- 조건:
  * 공통 치명 C1, C2, C3, C6: **0건 (단 1건도 불허)**
  * 기능 치명 이른 작별(E5-CRIT-04), 자기 호칭(E5-CRIT-07): **0건**
  * 직전 발화 반복(E5-CRIT-05): **0건**

### 5.2 기술 안정성 (Gate 2)
- 조건:
  * 포맷 실패 및 실행 중단(`text=None`) 비율 **10% 이하** (타임아웃, JSON 파괴, closing_failed 등)
  * 화자 1회 호출 타임아웃(20초) 초과율 **0%**

### 5.3 최종 품질 합격 (Gate 3 - 3턴 72줄 회귀 집합)
- 대상: **3턴 12개 대화 (총 72줄)**
- 조건:
  * 4개 평가 축 전 축에서 **평균 3.0점 이상 (5점 만점)**
  * 1점(불가) 판정을 받은 발화 **0줄**
- *(참고: 10턴/15턴 장기 대화 100줄은 별도 모니터링 표로 분리하여 트래킹)*
